Dinvolt gives your coding agent a working app, project instructions and recommended skills.

## Create a project

Copy the [project creation prompt](/agents/project-prompt) into your agent. It guides the agent through choosing a project type, running the CLI and checking the starter locally.

You can supply database credentials later. Ask for deployment or custom features as a separate task once the starter is ready.

## Extend an existing project

Give your agent a concrete task and ask it to read the project's instructions first:

```text
Read AGENTS.md, the README and the relevant integration guides.
Add a contact page using the project's existing UI components.
Run the available checks and verify the page in the browser.
```

The installed app is the source of truth. Keep its existing components, authorization checks and data patterns when adding features.

## Inspect setup without changing it

Run this from the generated project:

<CodeGroup>

```sh npm
npx dinvolt setup --status --json
```

```sh bun
bunx dinvolt setup --status --json
```

```sh pnpm
pnpm dlx dinvolt setup --status --json
```

```sh yarn
yarn dlx dinvolt setup --status --json
```

</CodeGroup>

The result tells the agent which setup steps are complete or pending.

## Add components without prompts

For example, install a dialog and a textarea into the public UI area:

<CodeGroup>

```sh npm
npx dinvolt ui add dialog textarea --target public --json
```

```sh bun
bunx dinvolt ui add dialog textarea --target public --json
```

```sh pnpm
pnpm dlx dinvolt ui add dialog textarea --target public --json
```

```sh yarn
yarn dlx dinvolt ui add dialog textarea --target public --json
```

</CodeGroup>

The `create`, `setup`, `ui add` and `vercel setup` commands support `--json` and `--no-input`. JSON mode disables prompts, writes one result to stdout and sends progress to stderr.

After a failure, inspect the exit code, result status and completed steps before retrying. A project or remote operation may already exist.

See [JSON results](/reference/json) and [non-interactive creation](/reference/create#non-interactive-creation) for details.

## Verify the result

Ask the agent to report what it actually tested: code checks, browser behavior, authentication and database reads or writes, as applicable. A passing build alone does not verify all of those flows.

Continue with [agent skills](/agents/skills) to maintain the instructions installed with your project.
