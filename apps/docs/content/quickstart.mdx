## Before you begin

Install **Node.js 24 or later**, **npm** and **Git**.

You can use npm, Bun, pnpm or Yarn for the generated app. Install your preferred package manager before starting.

## Create a project

Run this command from the folder where you keep your projects:

<CodeGroup>

```sh npm
npx dinvolt@latest create
```

```sh bun
bunx dinvolt@latest create
```

```sh pnpm
pnpm dlx dinvolt@latest create
```

```sh yarn
yarn dlx dinvolt@latest create
```

</CodeGroup>

In the wizard:

1. Name your project, for example **my-app**.
2. Choose **Create a new folder**.
3. Select a [project type](/project-types).
4. Choose **Use Dinvolt defaults**, or **Advanced configuration** to customize the setup.

**Using npm, pnpm or Yarn?** Select it in advanced configuration. Defaults use the package manager detected in the destination, or Bun in an empty project.

For projects with an admin panel, you can select **Complete credentials later**. This lets you explore the public page before connecting a database.

## Run locally

Enter your new project and use the package manager selected in the wizard:

<CodeGroup>

```sh npm
cd my-app
npm run dev
```

```sh bun
cd my-app
bun run dev
```

```sh pnpm
cd my-app
pnpm run dev
```

```sh yarn
cd my-app
yarn run dev
```

</CodeGroup>

Open the URL printed by the server, normally **https://my-app.localhost**. Portless manages local HTTPS and may ask you to trust its certificate on first use.

You should now see the public starter page. Keep the server running while you build.
